# 아이들 자기주도 학습 앱

아이가 매일의 학습 숙제를 스스로 체크하고, 하루를 다 끝내면 스탬프를 모아
최종 선물까지 받는 자기주도 학습 웹앱입니다. 아이 한 명당 앱 하나씩, 두 가지 버전이 있습니다.

| 폴더 | 앱 | 테마 | 바로 실행 파일 |
|---|---|---|---|
| [`app/`](app) | 민건이의 오늘 우주 미션 | 어두운 네온 우주 (우주 과학자) | `app/민건이의-우주미션.html` |
| [`app-mingyeol/`](app-mingyeol) | 민결이의 오늘 동화나라 모험 | 밝은 파스텔 동화나라 | `app-mingyeol/민결이의-동화나라모험.html` |

두 앱은 **기능과 동작이 동일**하고 이름·테마만 다릅니다.
저장키가 각각 `mingeon-*` / `mingyeol-*` 로 분리되어 있어, 같은 기기에서 둘 다 써도 기록이 섞이지 않습니다.

## 바로 쓰기 (설치 필요 없음)

각 폴더 안의 `.html` 파일을 **더블클릭**하면 브라우저에서 바로 열립니다.
서버도 npm 설치도 필요 없고, 태블릿/노트북에 그 파일 하나만 복사해도 동작합니다.

> 기록(모험·스탬프·달력)은 브라우저 LocalStorage에 저장되므로
> **같은 기기, 같은 브라우저**에서 열어야 이어서 쌓입니다.

## 개발 환경으로 실행

```bash
cd app            # 또는 cd app-mingyeol
npm install
npm run dev       # http://localhost:3000

npm run standalone   # 단일 HTML 파일 재생성
```

## 주요 기능

- **오늘의 미션 체크** — 카드를 누르면 완료되고 진행바의 캐릭터가 목적지로 전진
- **스탬프 보드** — 하루 미션을 모두 끝내면 스탬프 1개 (최대 30개)
- **축하 화면** — 전체 완료 시 컨페티 + 부모님이 설정한 보상 문구
- **30개 달성 대형 축하** — 최종 선물 문구와 함께 특별 화면
- **부모님 관리 센터** — 덧셈 문제로 잠금 해제 후 미션 추가/삭제, 보상 문구 설정,
  스탬프 수동 조정, 최근 7일 성공 로그 확인
- **효과음** — Web Audio API로 합성 (우측 상단에서 음소거 가능)

## 기술 스택

React 19 · Vite 6 · Tailwind CSS v4 · Motion · canvas-confetti · TypeScript
