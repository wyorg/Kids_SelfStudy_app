# 🚀🏰 우리 아이 오늘의 미션

아이가 매일의 학습 미션을 스스로 체크하는 웹앱입니다.
**여러 아이(프로필)** 를 등록할 수 있고, 아이마다 **우주 미션** / **동화나라 모험** 두 가지 테마 중 하나를 고를 수 있습니다.
React 19 + Vite 6 + Tailwind CSS v4 + Motion + canvas-confetti 기반.

## 방법 1. 그냥 바로 쓰기 (설치 필요 없음)

`우리아이-오늘의미션.html` 파일을 **더블클릭**하면 브라우저에서 바로 열립니다.
서버도 npm 설치도 필요 없고, 태블릿/노트북에 이 파일 하나만 복사해도 동작합니다.

> 기록(미션·스탬프·달력)은 브라우저 LocalStorage에 저장되므로
> **같은 기기, 같은 브라우저**에서 열어야 이어서 쌓입니다.

## 방법 2. 태블릿·모바일에 설치 (PWA) — 배포본

Vercel로 배포하면(이 폴더가 배포 루트) 홈화면에 **앱 아이콘으로 설치**됩니다.
- Android/Chrome: 주소창 메뉴 → "앱 설치" / "홈 화면에 추가"
- iPhone·iPad/Safari: 공유 → "홈 화면에 추가"
- 오프라인에서도 열리도록 서비스 워커(network-first)가 동작합니다.

## 방법 3. 개발 환경으로 실행

```bash
npm install
npm run dev          # http://localhost:3000
npm run build        # dist/ 생성 (Vercel 배포본)
npm run standalone   # 우리아이-오늘의미션.html 재생성
```

## 주요 기능

- **여러 아이 프로필** — 상단 바에서 아이를 전환. 아이마다 이름·테마·진도(미션/스탬프/달력)를 **따로** 저장
- **테마 2종** — 우주 미션(어두운 네온) / 동화나라 모험(밝은 파스텔). 부모님 센터에서 언제든 전환
- **오늘의 미션 체크** — 카드를 누르면 완료되고 로켓🚀/열기구🎈 가 목적지로 전진
- **스탬프 보드** — 하루 미션을 모두 끝내면 스탬프 1개 (최대 30개)
- **축하 화면 / 30개 대형 축하** — 컨페티 + 부모님이 설정한 보상·선물 문구
- **부모님 관리 센터** — 덧셈 문제로 잠금 해제 후: 프로필 추가/삭제·이름·테마 설정,
  미션 추가/삭제, 보상 문구, 스탬프 수동 조정, 최근 7일 로그
- **효과음** — Web Audio API 합성 (우측 상단에서 음소거)

## 구조

- `src/App.tsx` — 셸: 프로필 관리 + 테마 선택 + 상단 전환 바
- `src/themes/SpaceApp.tsx` — 우주 테마 화면
- `src/themes/FairytaleApp.tsx` — 동화나라 테마 화면
- `src/appShared.ts` — 두 테마 공통 로직(효과음, 한국어 조사용 이름 변형, 프로필 타입)
- 프로필별 저장 키는 `<프로필id>-missions`, `<프로필id>-stamps` … 형태로 네임스페이스됨.
  최초 실행 시 기존 `mingeon-*`(민건/우주) 데이터를 잇는 기본 프로필이 자동 생성됩니다.

## 원본 사양 대비 수정/확장 이력

원본 `CLAUDE_CODE_EXPORTS.md`(단일 우주 앱)에서 출발해 아래를 고치고 확장했습니다.

1. `package.json` — `"^18.2.0" || "^19.0.0"` 형태 JSON 문법 오류 → 단일 버전 정리
2. `package.json` — 누락된 `@vitejs/plugin-react` 추가
3. `vite.config.ts` — ESM에서 못 쓰는 `__dirname` → `import.meta.url` 기반
4. `tsconfig.json` — `npm run build`(tsc)에 필요하여 추가
5. `src/App.tsx` — `restoreDefaultMissions()`의 히스토리 저장 인자 버그 수정
6. 설치형 PWA(매니페스트·아이콘·서비스워커) 추가
7. 아이 이름 변경 → **여러 아이 프로필 + 테마 전환**으로 확장 (동화 테마는 기존 `app-mingyeol`을 흡수)
